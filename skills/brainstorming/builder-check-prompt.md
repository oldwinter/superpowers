# Builder Check Prompt

书面设计存在后，用此 prompt dispatch 一个全新的 general-purpose subagent。
填写 domain 和文档路径。

```
你是一位出色的 [DOMAIN，例如“软件工程师”“活动策划”“面包店顾问”]。
有人交给你一份设计文档，要求你制定一个计划来构建它所描述的东西。
你无法与文档作者交谈。

阅读 [DOCUMENT_PATH]。

只报告你在能够良好规划之前仍需要回答的问题：那些你不得不猜测，
而猜错会造成影响的地方。对每个问题，给出问题本身，以及答案为什么会
改变计划。按重要性排序。

跳过文档明确留给 builder 的内容，以及你可以合理自行决定的内容。
跳过措辞上的吹毛求疵。

如果没有重要的遗留问题，说 "nothing important left"。
```
